# 06 验收：每条都要能跑出红绿

两条腿：**机器判据**（脚本 + 退出码）与**截图基线**（人眼看，但要能 diff）。没进这张表的「感觉好多了」不算验收。

## 视口

| 代号 | 尺寸 | 用途 |
|---|---|---|
| P1 | 1180×820 | 主对象（平板横屏） |
| P2 | 1024×768 | 老 iPad 竖屏/小横屏下限 |
| P3 | 1366×1024 | 笔记本浏览器 |

## 数据状态矩阵（每屏至少覆盖 3 种）

| 代号 | 状态 |
|---|---|
| D0 | 全空（新用户，无记录） |
| D1 | 有 1 组记录，全对 |
| D2 | 有记录，含错题与「看了答案」 |
| D3 | 有跳过 / 空卷 / 「判不了」 |
| D4 | 长内容（13 个方法、13 个知识点的节、2708 题里的任意节） |

## 判据（A 组，机器可判）

| ID | 判据 | 怎么量 |
|---|---|---|
| A1 | 每屏都有下一步 | 每路由至少 1 个可点出口，且不是「改地址栏」 |
| A2 | 无横向溢出 | `scrollWidth <= clientWidth + 1`，逐路由 |
| A3 | 文字不被裁 | 按钮/标签 `scrollWidth <= clientWidth`；关键按钮 `rect.right <= innerWidth` |
| A4 | 字号下限 | 正文 ≥ 14px（CSS 像素），非公式文本不得更小 |
| A5 | 可点目标 | 触控目标 ≥ 40×40（主操作 ≥ 44×44） |
| A6 | 数字自洽 | 屏幕上「做对 + 没做对 + 跳过 + 判不了 = 总数」 |
| A7 | 节号一致 | 任一屏出现的节号必须属于当前组的节 |
| A8 | 无写死文案 | 源码里搜不到「12.1 三角形」「回到今天」这类硬编码（按白名单） |
| A9 | 公式不劈行 | `.katex` 的多个 rect top 差 < 6px |
| A10 | 空态可读 | 空态页必须有「为什么空 + 下一步」两句 |
| A11 | 控制台零报错 | 12 路由 console error / unhandledrejection 为 0 |
| A12 | 交卷可达 | 题号区换行后，「交卷」在 P1/P2 都完整可见（FD-12） |

## 截图基线

- 第一版基线在 R3 结束时生成：`design/ux-v2/shots/base/<视口>-<路由>.png`。
- 之后每次改动跑一次，diff 只列变化张数与像素差；**基线更新必须显式声明**（不许悄悄覆盖）。

## 不算数的验收

- 只在 1180×820 点过一遍；
- 只看字符串在不在、不看它在哪、有没有被裁；
- 「开发自测通过」当验收结论；
- 判据本身写错导致假绿（必须做一次负例：故意改坏 → 必须红）。
