# 原型说明

这一版是可点的静态页面，用来看立方根这一条内容在节页、图谱、知识点和练习上怎么走。它不接题库，也不代替现有产品。

## 怎么打开

用浏览器直接打开这个文件：

`math-coach/design/ux-round2/prototype/index.html`

地址栏会是 `file://` 开头。不需要启动本地服务器，也不用改 `runtime/`。

打开后进入今天页。若地址栏还没有哈希，页面会补上 `#/today`。

左侧可以点「今天」「课本」「图谱」。节、知识点、方法和练习从页面里的按钮进入。

## 路由

| 哈希 | 页面 |
|---|---|
| `#/today` | 今天。这一节是 11.2 立方根，并有一道题的入口 |
| `#/book` | 课本。只展开八年级上册第 11 章 |
| `#/section` | 11.2 立方根 |
| `#/map` | 图谱分层。四列是节、知识、方法、思想 |
| `#/map?view=panorama` | 图谱全景。仍属于图谱，不是另一套数据 |
| `#/kp` | 知识点「立方根定义」 |
| `#/method` | 方法「求一个数的立方根」 |
| `#/practice` | 练习。只有 ∛8 这一题 |

分层和全景用页面上方的「分层」「全景」切换。

## 页面上放了什么

只使用已经写明的这一套内容：八年级上册第 11 章 11.2，课本第 43 页，知识点「立方根定义」。

- 定义：如果一个数 x 的立方等于 a，即 x³=a，那么这个数 x 叫作 a 的立方根，也叫三次方根，记作 x=∛ a。页面上的立方根用仓库里的 KaTeX 画成 `\sqrt[3]{...}`，不用上标 3 加一个平方根号。句子没有改。
- 成立：被开方数 a 可以是任意实数。
- 别混成：立方根与平方根不同，被开方数可以是负数；∛ a 只有一个值，不用写 ±。
- 容易错成：把 ∛8 写成 ±2。
- 要会：求一个数的立方根；用符号表示立方根。
- 前置是乘方。后置是「任何数都有唯一的立方根」「负数的立方根是负数」「用计算器求平方根和立方根」。
- 方法三步是：先看这个数的符号；再找出哪个数的立方等于它；最后写出唯一的结果，符号与原数一致。
- 思想是「逻辑推理与证明」。页面写「这一节里这样用」，并列出上面这个方法。这里没有给思想另写定义。
- 练习题是「∛8 的值是（ ）」。选项是 2、±2、4、±4。2 为对，其余为错，错因是「立方根只有一个值」。

节页在「立方根定义」下面写出上面这句定义。方法名是按钮，点进去是 `#/method`。

分层选中「立方根定义」时，知识列里写着「先要会 乘方」「当前」「接着学」和三个后置。右侧卡片写定义、成立、别混成、容易错成和课本第 43 页。

全景的中心是立方根定义。前置的箭头指向中心，后置的箭头指向外面。方法用虚线，不靠颜色单独区分。图用页面里的 HTML 和 CSS 画出，没有另接图谱库。

知识点页有定义、别混成、前置 / 当前 / 后置三列，以及方法按钮。「再练这一题」进入练习。

练习页先显示题干和四个选项。提示默认收起，点「打开提示」后才看到五级里的第一级「重述题意」。

## 哪些是示意，不是全库

- 课本没有其他册、章、节。第 11 章也只放了 11.2。
- 练习只有 ∛8 这一题，不是一节多题，也不是方法下的整组题。
- 「乘方」和三个后置只写名称，用来表示先学什么、接着学什么。本原型不为它们另开定义页。
- 全景只画这一焦点周围的几条关系，不是全书。
- 提示按五级来做，这一版点开后只展示第 1 级。后面四级不展开。
- 没有回顾、记录、搜索，也没有掌握百分比。
- 蓝框只表示当前选中的「立方根定义」。关系靠箭头方向和虚线区分。
