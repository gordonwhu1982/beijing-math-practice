## 怎么读

- **事实**：下面的路由、块、文案都能在上述三个文件里对上。文案用「」括原文。函数名保持原样。
- **推测**：只写代码分支能推到哪一步。图谱节点正文、题干、题量不在这三份文件里，标 **NOT_VERIFIED**。
- 壳：`index.html` 只有左栏 `#nav` 和主区 `#main`。页内容由 `render()` 把 `topBar()` 和对应 `view*` 写进 `#main`。标题是「math-coach 原型 · 平板练习」。

- 默认状态：`route` 为 `today`，册 `801`，章 `12`，节 `12.1`，`kpName` 为「三角形的定义」，`mapMode` 为 `layer`，`mapBook` 为 `801`，`mapChapter` 为 `801-12`，`kpBand` 为 `olympiad`。

## 结果 `viewResult`

1. 路由：`#/result`。有顶栏。返回 `homeRoute()`：节测回节，章测回章，其他测试回回顾；`drill` 回 drill；`kp` 回知识点；`today:one` 回今天；`section` / `chapter` / `map` 回节；其余回今天。面包屑「这一组结果」。
2. 标题、总结句、色条、可选测试句、分组列表、底栏说明和按钮。分组：「做错了」「看了答案」「跳过了」「等你自己判」「做对了」（默认收成「做对了 N 题 · 展开」）。每行：序号、题干前 30 字、知识点名、状态。状态词：「做对了」「做错了」「空着交」「看了答案」「跳过了」「等你自己判」「还没做」。
3. 总结：「这一组 N 题：a 对，b 错，…」全跳过则「这一组都跳过了。」测试后若有 `testBack`：「刚测完：稳了 N 个，还不稳 M 个」。底栏：「没做对的 N 道已放进回顾，之后还能再做。」做对了原先要重做的：「这 N 道已从回顾里移出。」
   - 标题：测试「这一组的结果 · 测试」；只练错的「这一组的结果 · 只练错的」；其余一律「这一组的结果 · 12.1 三角形」。11.2 练习交卷也会用最后这句。
   - 行内「看解析」展开的第三段是 `HINTS[4]`，不是该题 `explain`。
   - 「再来一组」的题池是 `againPool()`，从 `QUESTIONS` 里去掉本轮做对的，不是当前 `BANK` 队列。
   - 非测试的底栏主路径写「回到今天」，即使这组从节或知识点进来。返回按钮才走 `homeRoute()`。
4. 空 / 加载：队列空：「这一组的结果找不到了。」「回到今天」。`?load=1`：「正在打开……」。`?sample=1` 且队列空会种入六题示意样本。
5. 跳转：按来源，「回到这一节」「回到这一章」「回到回顾」「回到今天」「只练错的」「把跳过的做完」「再来一组」都进练习或对应页。「回到知识点」→ `#/kp`，`kpName` 取 `questionById(id).kp`。示意题因此是中文名，进写死版。题库题的 `kp` 是 `rememberRow` 写的 `kps[0].name`，不是 uid；会不会撞上四个中文名以外并画成「三角形的定义」，取决于题库 name 字段，**NOT_VERIFIED**。「现在做」「重做这道」→ `#/practice` 单题。「对了」「不对」留在结果页改标记。
