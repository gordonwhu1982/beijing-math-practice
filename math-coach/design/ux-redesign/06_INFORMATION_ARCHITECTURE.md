## 0. 本版的几条边界

- 这一版不做手机专用布局。设计基准是平板横屏，参考视口沿用 04 审计的 1180×820。手机小屏和普通桌面窗口只要求能正常显示、能渲染。
- 不把依据总览当成孩子的主任务。依据总览给维护仓库的人看，见 §6.2。
- 不改 `runtime/`、`content/`、`tools/` 和现有页面。下文的「新页面 ID」是设计稿编号，不是代码路由。新旧怎么对应写在 §6，实现时是否沿用现有路由由后续开发决定。
- 2026-10-28「最终界面尽量照竞品」这一决定在本版重审，结论见 §7：借图谱层次和前置/当前/后续，不整页照搬。
- 竞品材料写明它不卖题、不做题库（05 §4.1、§4.7）。本产品的练习、测试、回顾、评估全部保留，并且是孩子的主任务。

## 1. 平板网站给孩子的主任务

孩子用平板打开网站，按今天这一节做题，做完马上知道哪里错了，能顺着错题回到对应的知识点弄懂再练；需要时从课本目录或知识图谱找到某一章、某一节先看懂。

图谱和知识体系是「弄懂」这一步的工具，不是首屏任务。这和竞品「假设用户有查找任务」（05 §4.1）的出发点不同，这里假设孩子有学习任务。

### 3.1 页面结构里要解决的现状问题

只写信息的先后，不写视觉。

- P-TODAY：第一屏只放「今天练哪一节」和开始按钮。排查字体的说明条（OBS-001）不出现在孩子的页面上。
- P-SECTION、P-TODAY：同一节的题量只在一处按同一口径写，开始练几题写在按钮上，不出现 84 题和分档合计对不上的情况（OBS-002）。
- P-SECTION：顺序是这一节讲什么 → 知识点 → 方法 → 常见错因 → 开始练。题量条不放在第一屏（OBS-004）。
- P-KP：顺序是定义和例子 → 前置/当前/后续 → 方法和思想 → 练这个知识点。前后数字、题号标签和课标编号放在正文之后（OBS-005）。
- P-KP、P-MAP：符号空位（OBS-006）是内容渲染缺陷，信息架构上要求带符号的文字原样显示，不把它当成可以接受的现状。
- P-MAP：默认进入分层，打开时带上当前所在的册和章（OBS-007 里册还是「六册全部」）。全景是图谱内的一个视图切换，必须能点中，切换后仍停在刚才的章（OBS-010）。读知识点卡片时图谱仍在旁边（05 §4.5、§5 表）。
- P-PRACTICE：这一节因为题在图上而没收进来的题，在 P-SECTION 写一次即可，不写进第一道题的题干（OBS-003）。

## 4. 三条核心旅程

### 4.1 今天练一节，做完看结果，错的能回到知识点再练

| 步骤 | 页面 | 孩子做什么 |
|---|---|---|
| 1 | P-TODAY | 看到今天推荐的一节，点「开始练」 |
| 2 | P-PRACTICE | 一题一题做，卡住时按需要提示 |
| 3 | P-RESULT | 交卷后看对了几道，哪几道错了 |
| 4 | P-KP | 点一道错题的「回到知识点」，读定义和例子，看前置是否也不会 |
| 5 | P-PRACTICE | 在知识点页点「再练这个知识点」，或回到结果页点「只练错的」 |
| 6 | P-RESULT | 看这次是否做对 |
| 7 | P-TODAY | 回到今天；没做对的题自动留在 P-REVIEW「要重做的题」 |

页面顺序：P-TODAY → P-PRACTICE → P-RESULT → P-KP → P-PRACTICE → P-RESULT → P-TODAY。

### 4.2 从课本或图谱进入一章专题，看懂这一节再做题

| 步骤 | 页面 | 孩子做什么 |
|---|---|---|
| 1a | P-BOOK | 从「课本」选八年级上册，再选一章 |
| 1b | P-MAP | 或从「图谱」的教材层、章节层点这一章 |
| 2 | P-CHAPTER | 看这一章有哪些节、主干知识和方法，选一节 |
| 3 | P-SECTION | 看这一节讲什么、有哪些知识点 |
| 4 | P-KP | 点开一个知识点，读完；需要时顺着前置去看 |
| 5 | P-SECTION | 回到节专题，点「开始练」 |
| 6 | P-PRACTICE | 做题 |
| 7 | P-RESULT | 看结果，错题按旅程 4.1 第 4 步回到知识点 |

页面顺序：P-BOOK 或 P-MAP → P-CHAPTER → P-SECTION → P-KP → P-SECTION → P-PRACTICE → P-RESULT。

### 4.3 回来看哪里不稳，再测一次

| 步骤 | 页面 | 孩子做什么 |
|---|---|---|
| 1 | P-REVIEW | 从导航「回顾」或今天页的提示进入，打开「不稳的地方」栏 |
| 2 | P-KP | 点一个不稳的知识点，看一眼定义和自己上次错在哪 |
| 3 | P-REVIEW | 回到回顾，勾选要测的不稳点，点「测一次」 |
| 4 | P-TEST | 不看提示地做这一组 |
| 5 | P-RESULT | 看哪几个点这次稳了，哪几个还不稳 |
| 6 | P-REVIEW | 回到回顾。稳了的点从「不稳的地方」移出，还不稳的留在上面 |
| 7 | P-RECORD | 需要时看各章的变化 |

页面顺序：P-REVIEW → P-KP → P-REVIEW → P-TEST → P-RESULT → P-REVIEW →（可选）P-RECORD。

## 5. 空状态

还没有任何作答记录时，四个地方说给孩子听的话。都不出现仓库命令、F12、文件名或 404 一类的字。

| 页面 | 要说的话 | 给孩子的下一步 |
|---|---|---|
| P-TODAY | 「还没开始练。先从这一节做 6 道题吧。」并写出推荐的节名和课本页码 | 「开始练」；「先看这一节」 |
| P-REVIEW「要重做的题」 | 「还没有要重做的题。做完一组题后，做错的会放到这里。」 | 「去今天的练习」 |
| P-REVIEW「不稳的地方」 | 「还看不出哪里不稳。多做几组题，这里会列出容易错的知识点。」 | 「去今天的练习」；「按课本目录挑一节」 |
| P-RECORD | 「还没有做题记录。记录只保存在这台平板的浏览器里，换设备或清理浏览器会看不到。」 | 「去今天的练习」；「导入以前的记录」 |

「记录只保存在这台设备的浏览器里」沿用现有档案页已有的说明（OBS-011），改成孩子能懂的说法。

### 6.2 需求变化和理由：合并或从孩子导航拿走的部分

这些改动不删除任何能力，只改变孩子从哪里看到它。每一条都要经独立评审确认。

1. **依据总览（PAGE-012）移出孩子导航。** 现有页面解释数字怎么来、图是草稿，并写出 `bash tools/check_all.sh` 等仓库命令（OBS-012）。这是给维护仓库的人的，孩子看不懂也用不上。页面保留，入口放在「我的记录」底部「关于这些数据」，维护者也能直接用地址打开。竞品字幕「每条关联，都有依据」（05 §4.2）要的是在一条关系上看到依据，这个需要在 P-KP 和 P-MAP 的关系上就地给一句来源，不靠孩子去打开总览页。
2. **前后知识点（PAGE-006）不再单独作为孩子要去的一页。** 前置/当前/后续本来就是在看一个知识点时才有意义的，竞品也是局部图形式（05 §4.2）。把它放进 P-KP 的一个区和 P-MAP 的局部图，孩子不需要多跳一页。现有路由能力保留，实现时可以直接定位到 P-KP 的这一区。
3. **思想（PAGE-007）放到次级。** 思想是知识体系的一层，孩子通常是在图谱或某个知识点上看到它。放进 P-MAP 的思想层和 P-KP 的思想条目，并保留「看全部思想」。现状里它只是今日正文的一行绿字（OBS-013），本来就不在主导航上，这一条是给它一个稳定的位置，不是降级。
4. **错题重练（PAGE-009）和哪里不稳（PAGE-010）合并成「回顾」一页两栏。** 两页做的都是「回来补」：一边是具体的题，一边是知识点。孩子回来时不需要先想清楚该去哪一页。合并后导航少一项，五项在平板上一眼看全。两栏的数据和判断规则不变。
5. **排查字体的说明条移出孩子页面。** 它提到 woff2、404 和 F12（OBS-001），盖住今日下半屏。这是给维护者的提示，改到 P-EVIDENCE 或开发者控制台。

### 6.3 需求变化：新增的页面

1. **P-TEST 测试。** 需求基线要求「练习、测试、回顾、评估」（01）。现有路由里没有独立的测试页，练习页有分级提示。本版把测试定为「不看提示地做一组题，结果计入不稳判断」，入口在节、章和不稳点上。题目来源、题数和计分规则留给 M5 和后续开发确认，不在这里假设现有数据已支持。
2. **P-CHAPTER 章专题。** 需求基线要求「各章专题」（01）。现有能力散在目录某一册的展开和图谱的 `ch` 档，04 审计没有作为独立页面看到。本版把它定为一页，承接从目录和图谱两头进来的孩子。
3. **P-RESULT 结果页。** 交卷后的画面 04 审计没有点到。本版把它定为旅程里必经的一页，因为三条旅程都要从这里决定下一步去哪。是否沿用现有交卷后的画面，等补点后再定。

## 7. 对 2026-10-28「最终界面尽量照竞品」的重审

- 竞品是上海教材高中数学的查找型图谱，材料写明不卖题、不做题库（05 §4.1）。本产品的使用者是北京版八年级上册的初二学生，主任务是练习。整页照搬会让首屏变成图和搜索（05 §4.1），把练习挤到次级，所以不执行整页照搬。
