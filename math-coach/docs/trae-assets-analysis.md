那个 1.7 GB 的旧工程里有三样 math-coach 正缺的东西：一套**初中几何三轴本体**（知识轴 34 叶 / 方法轴 25 方法 103 技法 / 任务轴 31 任务）、一个**4239 题的带标签题库**（其中 1588 题落在八上以外的竞赛·培优主题上）、以及一套**教研规则**（R1–R20）。前两样正好补「拓展、培优、竞赛知识点全空白」这个洞。

## 二、三轴本体是最高价值的东西

### 知识轴 `kp_tree.json`

编码 `学段-领域-主题-序号`（如 `J-GEO-TRI-04`）。34 个叶节点：

- **TRI 12 个** = 八上第 12 章（三角形概念 / 性质 / 主要线段 / 全等性质 / 全等判定 / 等腰 / 直角 / 尺规 / 逆命题 / 轴对称 / 勾股 / 勾股逆）—— 这 12 个我有对应，但我的粒度是 99 个细点。
- **其余 22 个是八上以外的竞赛·培优主题**：SIM 相似 3（比例线段与合分比、平行线分线段成比例、相似判定与性质）、ARA 面积 2（面积公式与面积法、共角共边与面积比）、CEV 共点线 4（角平分线与角平分线定理、中线与重心、三角形四心与欧拉线、塞瓦与梅涅劳斯）、CIR 圆 5（外接圆与圆周角、内切圆与旁切圆、根轴与圆幂、四点共圆、托勒密）、CON 构造 4（共点与共线、几何不等式、极值与最短路径与费马点、尺规作图与存在性）、TRF 变换 4（轴对称、旋转、平移、位似）。
- 每个叶带 `prereq`（前置链，`max_depth` 6 且强制无环）、`competition_relevance`（低/中/高，比如 TRI-01 低、CEV-01 高）、`prereq_depth`。
- 还有 8 个外部锚点（只读登记别的分类体系）、27 条映射、20 条候选层条目。候选层是「体系不够用」的可见出口。

### 方法轴 `method_tree.json`

6 族 25 方法 103 技法，两级编码 `M-SYN-04` / `M-SYN-04-T1`。关键字段：

- 方法带 `tool_level` 1–4（1 课内可直接用 / 2 需少量补充 / 3 需高中工具 / 4 需进阶或大学工具）与 `knowledge_link`（这个方法服务哪些知识叶）。
- **技法带 `recognition`：一句话说明「什么情况下该想到这招」**，比如 `M-SYN-01-T1 执果索因` 的 recognition 是「结论形式复杂、正向推导推不动时，从结论倒推所需条件」。这正是提示阶梯 L3 该说的话。
- 技法 tool_level 分布：L1 **23** / L2 **31** / L3 **32** / L4 **17**。方法分布：L1 8 / L2 9 / L3 6 / L4 2。
- 25 个方法全名单：分析法与综合法、反证法与同一法、辅助线与构造、旋转法、轴对称与反射法、平移法、位似与相似法、面积法、三角法与正余弦定理、代数法与方程法、割补法、比例与共点共线定理、坐标法、向量法、复数法、重心坐标与面积坐标、反演变换、射影与调和点列、完全四边形、极端原理、几何不等式与放缩、存在性与构造、抽屉原理与不变量、染色与赋值法、图论方法。

### 任务轴 `task_tree.json`

7 组 31 任务（`T-CALC-01 求线段长度` 这种），每个带 `recognition` + `methods[]` + `knowledge[]`。这是「看到题先判任务类型」的入口，math-coach 现在没有这一维。

### 难度模型 `difficulty_model.json`

`score = round(100 * (0.24*K + 0.26*R + 0.20*C + 0.18*I + 0.06*P + 0.06*V) / 5)`，五档 D1–D5 配额 950/…，15 个外部锚点（AMC8、希若杯、AIME、CMO、IMO…），`curriculum_distance` 四档由 `tool_level` 与知识叶共同判定。**与 math-coach 的 skill.tier 是同一套设计血脉**（六维权重完全一致），可以直接对齐而不是重写。

## 六、建议的接入顺序（按性价比）

### A. 把三轴本体接进来，给 skill 打标准码（1–2 天）

把 `method_tree` / `task_tree` 落成 `content/framework/method_tree.json`（只读参考层，不改现有实体），给 skill 增三个可选字段 `method_code` / `technique_code` / `tool_level`；再用 103 技法批量生成 skill 骨架，按 tool_level 分层：L1（23）→ 挂到对应八上节当 core，L2（31）→ extend，L3+L4（49）→ olympiad。skill 从 125 涨到约 170，且每条都有标准码，能与外部体系对齐。

### B. 补 22 个竞赛知识点（2–3 天，最直接的「填补空白」）

不照搬 34 叶，而是按「北京版八上能挂到哪一节」重写：塞瓦与梅涅劳斯、托勒密、根轴与圆幂、四点共圆、四心与欧拉线、费马点、反演、射影与调和点列、完全四边形、位似、相似三定理、面积比与线段比……每个新点写定义、边界、条件、先修边，标 `tier=olympiad`。做完之后你的图谱第一次出现「塞瓦定理」「托勒密」「费马点」这些名字，而 1588 道题也终于有了落点。

### C. 用 4239 题的真标签校准映射器（1 天）

现在词表映射器严准 86.2%，但只在第 12 章 1242 题上验过。4239 题有 `kp_primary` 真标签，可以先把 J-GEO 34 叶与 K801 99 点做人工映射（之前实测：精确 7 / 子串 8 / 未命中 27），再抽 200 题交叉验证，反向修词表与权重。

### D. 加两个新维度：任务类型与题型风格（各 0.5 天）

`task_tree` 的 31 个任务（求长度 / 求角度 / 求面积 / 求比值 / 证明相等 / 证明共线…）与 exam-library 的 12 种风格，是图谱现在完全没有的两维。任务类型可以直接做成 skill 的新分类维度，题型风格可以做成 question 的 `style` 标签。

### E. 明确不接的

- olympiad-bank 685 题的答案（多为证明题、cite-only、与北京版课内无交集）
- 3547 张 page-raster 配图（cite-only，绝不进公开仓）
- 300 多个 `s6xx_*.py` 录入脚本与 70 多个 `.bak`（一次性过程产物）
- 13 个审计目录里的 html 报告（过程产物，不是结论）

## 七、风险

1. **全部是 `ai_draft`**：这套本体是旧工程的 AI 产物，`competition_relevance`、`tool_level`、六维难度评分都是规则推断（`calibration.status = rule-based estimate, not measured`），不是评测结果。接进来必须保留这个标记。
2. **两套码不通用**：`J-GEO-*` 34 叶与 `K801-*` 673 点是两套体系，映射是人工活，之前实测精确 7 / 子串 8 / 未命中 27（34 叶中）。
3. **许可**：3547 张整页栅格 cite-only；olympiad-bank 的真题题干也属引用性质。
4. **命名粒度冲突**：J-GEO 把整个八上第 12 章压成 12 个叶，math-coach 拆成 99 个细点。接的时候是「叶 → 多点」一对多，不能反向。
