# 方法之间的先后（skill_prerequisites.json）

教材写知识点之间的先后（哪节在前），但不写**方法**之间的先后。可是孩子卡住的时候，问的往往不是「这个知识点是什么」，而是「这道题该先想哪一步」——这需要方法层面的先练/后练。这份文件就是方法级先修边的权威源。

## 走过的两条弯路（都实测过，都不成立）

### 第一版：由「挂点位置」反推（规则 skill_dep_by_kp）

801 的方法带 kp_refs，里面混着「应用点」和「依赖点」。第一版假设：某条方法的挂点严格早于本节，那些点上挂着的其它方法就是它的前置。产出 16 条，量太小（同节内的先后全被丢掉；当时点级先修 832 条里 573 条落在同一节内）。

### 第二版：由「点级先修一跳」反推（规则 skill_dep_by_kp2）

换成「P 是 Q 的先修点、P 挂 a、Q 挂 b，则 a 是先练 b 的前置」，P 挂 3 条以上方法时跳过（点太泛），每方法入度上限 6，加边前做可达性检查防成环。产出 821 条。

**2026-10-28 抽检 40 条（种子 20261028）**：对 20 条（50.0%）、偏 7 条（17.5%）、错 13 条（32.5%）。

错的三类：
1. **并列或互逆被当成先后**：用求根公式解一元二次方程 → 用十字相乘分解求根；按公共点个数判断直线与圆的位置关系 → 用 d 与 r 比较判定；把解集画到数轴上 ↔ 看着数轴写出解集；用公式求对称轴与顶点坐标 → 用对称轴判断增减性（方向反了）。
2. **通用策略被当成具体方法的先修**：先求易求的量再逐步推进、用两步法判定正方形 → 用包含关系定位平行四边形家族。
3. **跨册远距离反推**：K701 判断一条射线是不是角的平分线 → K801 作倍长中线构全等（毫无因果）。

### 收紧了反而更差

假设病根是「把同节教材顺序当依赖」。于是把点级先修拆成人工边与顺序边，3c 只用人工边重跑，821 → 264 条。

**再次抽检 40 条**：对 11 条（27.5%）、偏 11 条（55.0% 含偏）、错 18 条（45.0%）。比收紧前更差。

**结论：这条反推路本身不成立。** 点级先修回答的是「能不能学这个点」，方法级问的是「先练哪条做法」；一个知识点上通常挂着好几条做法（不同应用场景），点与点之间的先后推不出做法与做法之间的先后。整段规则从 edges_build.py 删掉，改为读这份手工起草的文件。

## 现在的做法

**385 条逐条起草，六册齐**，每条写 why：

- `from` = 先练的方法，`to` = 接着练的方法
- `why` = 「要学会 to，为什么得先会 from」的一句话依据，落到 to 的具体步号
- 文件级 `review_status` = `ai_draft`：起草者看过教材与教学方法，但**没有教研复核**

按册：801 **96**（其中 83 条第一轮起草、13 条第二批补）、701 **65**、702 **71**、802 **48**、901 **63**、902 **42**。相对派回条数删了 9 条弱边（701 删 3、702 删 1、802 删 2、901 删 3），删的标准只有三种：

1. **同一做法换名字**：七上「把减法改写成加法」→「把加减混合算式统一成加法」，后者就是把前者连用整个式子，不是两件事。
2. **方向反了**：八上「用度量工具验证作图」→「用作图工具过一点作平行线或垂线」——实际是先会作图才谈验证。
3. **why 写的是「常与…配合使用」**：那是并列，不是先后。

生成后与按教材位置判定的 16 条（规则 skill_dep_by_kp）合并去重：385 条里 6 条与那 16 条重合被去重，**净入 379 条**，方法→方法合计 **395 条**，无环。

## 校验与闸门

- `tools/edges_build.py` 读这份文件，产出 `prerequisite_of`（方法→方法），strength=support、confidence=inferred、rule=skill_prerequisite_draft
- `tools/relations_check.py` 守不变量：端点必须存在、无自环、无环
- `tools/web_detail_probe.js` 断言方法详情里出现「先练哪个」块且写明「逐条起草」「还没有教研复核」
- 前端：图上画成**虚线箭头**（x=sk），与教研确认过的实线先修一眼可分；方法详情出「先练哪个」块

## 覆盖与空白

- 已起草：六册 412 条草稿，入表 422 条；按 to 去重后 **349/667 = 52.3%** 的方法知道「先练什么」（入表后按册 801 73% / 701 38% / 702 50% / 802 51% / 901 47% / 902 61%）。条数比方法数多，是一条做法有时有两个前置
- 未起草：**318 条方法没有任何入边**。早先逐个核对过的入口做法（约分、通分、勾股定理、判轴对称、求平方根、作线段等于已知）仍然不需要前置
- 2026-10-29 补了几何链上 14 条，后来又按步骤原文补了合并同类项、待定系数、判别式、求根公式、配方法和全等转移，跨册一共 23 条。五步法里的移项和「正确移项」互相指向，那条成环的边已删。没有恢复点级反推

## 怎么用，别怎么用

可以：把它当线索——「这条方法之前，孩子可能还不会这几条」，点进去看详情，再决定要不要补。
别：拿它判「学生必须先学 A 才能学 B」。它没有教研签字，而且方法之间的先后本来就允许绕行（很多孩子先会算再懂为什么）。
