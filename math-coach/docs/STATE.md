## 1. 怎么跑

    cd /d/个人/知识图谱/math-coach
    python -m http.server 8080          # 必须走 HTTP：file:// 下 fetch 与 ES module 都会被浏览器拒绝
    # 浏览器打开 http://127.0.0.1:8080/runtime/web/

    bash tools/check_all.sh             # 数据 + 契约 + 渲染 + 判题 + 构建，约 1 分钟
    bash tools/check_all.sh --web       # 再加无头 Chrome 冒烟 45 条 + 详情探针 13 项，约 4–6 分钟

一次完整重建，**顺序不能乱**（边依赖内容，框架依赖边，前端依赖框架产物）：

    python tools/edges_build.py            # content/** → content/relations/edges.jsonl
    python tools/relations_check.py        # 边表闸门：成环 / 悬挂 / 语义 / 计数
    python tools/skill_prereq_check.py     # 方法先后草稿校验（uid 真实、无环、why 够长；跨册逐条起草允许）
    python tools/framework_gen.py          # → build/framework/nodes.jsonl（派生节点，含 title）
    python tools/build_web.py              # → runtime/web/data/*.js（catalog / graph / 每节三片）

需要 Node 24（内置 node:sqlite 虽然没用上，但 katex / cytoscape 校验脚本跑在 node 上）与 Python 3.11+。
第三方库已 vendored 在 assets/vendor/（katex、cytoscape、dagre、cytoscape-dagre），不装 npm 也能跑。

## 2. 现在能用什么（主导航十屏 + 两个二级页 = 12 条路由，每屏只回答一个问题）

| 路由 | 这一屏回答什么 |
| --- | --- |
| #/today | 今天做什么：继续上一节 / 还欠着的题 / 该抽回来的旧题 / 近 7 天 |
| #/toc | 按教材顺序，我学到哪了（每节「做过 n/m · 独立对 k」，每册一条进度条） |
| #/sec/<vol>/<no> | 这一节是什么、有哪些知识点与方法、例题、练习题入口、下一节去哪 |
| #/practice/<vol>/<no> | 做题。带 `?q=` 先看这一题，不整节开考；带 `?qs=` 或从「练这一节」进来才是一组题 |
| #/retry | 欠着的题跨节一次做完（错题重练） |
| #/weak | 哪里不稳：作答记录按知识点数出来，错的排前面 |
| #/map | 六册全景只到「章」：26 张章卡片 + 6 个册名，卡片上写整句章名，章与章之间只有「先修」和「教材顺序」两种线。点一张卡片进那一章，再看节与点（节名会写出来）。手机上这一档换成同序的整屏列表（画布缩到 0.37 倍时字只剩 4.8px）。旧的全景 / 章图 / 骨架留在「其他画法」 |
| #/rel/<kid> | 一个点卡住时看三列：先得会 / 就是这里 / 学完接着 |
| #/thoughts | 16 条思想各自覆盖哪些册、哪些方法 |
| #/evidence | 依据总览：三档依据各多少条、四类实体各覆盖多少（全部现算，不写死） |
| #/archive | 带走与带回来：导出 / 导入作答记录 JSONL（M4a） |
| #/kp/<uid> | 单个知识点的整页讲解（与图谱右栏同一份渲染） |

关键交互与规矩（改动前先读 docs/superpowers/specs/2026-10-27-chapter-map-design.md）：

- **判题三态**：correct / wrong / manual。判不了就写「这题我判不了」并让孩子自评，**永不把判不准显示成错**。
- **提示留痕**：L1 重述 → L2 定位 → L3 方法方向 → L4 给第一步；用过后做对记「带提示通过」，不计独立做对。
- **判错给四行卡**：卡在哪（知识点）/ 先得会（直接先修）/ 做法（一条方法）/ 回到图上（带节点 id 的链接）。
- **无点级映射时的诚实兜底**：只出两行，写「这道题还没标到具体知识点，先看这一节」。不知道就说不知道。
- **从知识点或方法看一道题**（提交 `a128978`，细则在 §11）：题卡按钮是「看这道题」，方法上的「用它做过的题」也是单题。先出题干和答案，另有「做这一题」。顶栏返回走链接里的 `from`，回到 `#/kp/<uid>`，或回到 `#/map?view=…&node=<uid>&read=1` 并重新打开详解。不要用浏览器历史返回导图，历史里的 `#/map` 不带打开的节点，详解会丢。「练这一节」仍是一组题。
- **图示**（提交 `f16f7cd`，细则在 §11）：平面几何的定义下面有「图示」。图来自 `content/framework/figures.json` 的点线标注，由 `runtime/web/js/fig.js` 画成 SVG。现在只有等腰三角形、三线合一、将军饮马三张。讲义整页图不入库。

## 3. 数据与代码的真相

三层，职责不能混：

1. **权威层 = Git 里的文本**（content/**/*.json、*.jsonl）。人可读、可 diff、可评审。改一条记录 numstat 是 2 2。
2. **构建层 = 一次性脚本产物**（build/**、runtime/web/data/**）。全部可重跑，已 gitignore，不进仓。

## 5. 闸门：每一步在挡什么

每次 `git commit` 会先跑 `python tools/check_commit.py`（本机钩子是 `.git/hooks/pre-commit`，脚本在 `tools/hooks/pre-commit`）。大约半分钟，只读，不改仓库。失败就没有这次提交。新克隆要自己把 `tools/hooks/pre-commit` 拷到 `.git/hooks/pre-commit`。不要加 `--no-verify`，除非这次就是在修一个已经坏掉的钩子。这次暂存里带了前端文件时，钩子会**自动加跑**无头浏览器冒烟（见本节末），约 4 分钟。

`bash tools/check_all.sh` 是更深的全量闸门，依次跑 15 步（`--web` 再加 3 步），任何一步非零即计入失败步骤数。它会重写边表和前端切片，所以不放进提交钩子：

| 步 | 挡什么 |
| --- | --- |
| 关系表派生 edges_build | 边表由内容派生，不能手改 edges.jsonl |
| 关系表闸门 relations_check | 成环、悬挂端点、关系与端点类型不匹配、计数漂移 |
| 方法先后起草 skill_prereq_check | uid 真实、无自环/重复/成环；跨册可以，但必须是逐条起草 |
| 框架派生 framework_gen | 骨架 → nodes.jsonl（title 由这里产生，很多文档脚本依赖它） |
| 横向对照表 analogies_doc --check | docs/analogies-table.md 与 analogies.json 不一致就红 |
| 选择题选项 question_options_extract --check | 侧挂 options 文件与重抽结果不一致就红（防 drift） |
| 字段契约 schema_check | 17 类实体的必填/枚举/引用存在性 |
| 题库校验 questions_check | 题字段、难度、答案存在性、禁词 |
| 评分点 rubric_check | 评分点合计与满分、序号连续 |
| 数学式 katex_selftest | 全库 KaTeX 真渲染，抛错即红（$ 内不允许换行） |
| 判题回归 judge_spec_test | 54 条判题用例（含关系式 L3 路径） |
| 判题一致性 judge_spec_audit | 每条 spec 的标准答案必须判 correct、错值必须判 wrong |
| 框架报告 framework_status | 生成 docs/framework-status.md（写死数字会被这里抓到） |
| 前端切片 build_web | 切片大小预算、节点/边计数 |
| 题→知识点 questions_kp_check | 2576 条映射的 uid 存在性、每点 primary 唯一 |

`K999-99.9-99`，2026-10-27 的旧截图里这一屏整句只有「知识点编号看不懂」，读者只能改地址栏。判据按结构判（`.empty` + 字数 < 240），不按措辞判：第一版按「没找到/看不懂」这类词匹配，而真实文案是「不像我们的格式」，判据自己一条都没命中。**点开一个点：标签不许叠、不许甩远、点团必须放大到 >=1 倍**（CHIP）：map-local 路由先用 MC.mapView.pick() 打开焦点（pick 早一步会静默返回 false，量到 null 还显示 [ok]，所以要重试到 .call-chip >= 4 才量）。量三件事：标签两两重叠对数必须 0、最长引线 <=220px（标签该贴着点，不能甩到画布另一边）、 cy.zoom() >= 1（2026-11-03 之前 cy.fit 把节点文字算进 bbox，倍率掉到 0.65，点团只占画布三分之一， 用户原话「看不清，也没有焦点」）。**焦点态只剩中心那圈线（FOCUS）**：地址里带 `node=` 就是焦点态，此时画着的线必须 ≤ 焦点节点的度 + 1（至少给 6 根余量），量的是渲染后的 `opacity > 0.05` 而不是类名——2026-11-02 ux 复验实测「点开一个点，3698 条边仍然 0.12 全可见」，根因是 ## 10. 踩过的坑（照着躲，都是真踩过的）

1. **run_code 的模板字符串（含 String.raw）里出现反引号会立刻截断**。写含 markdown 反引号的脚本时，正文里先用 ` 占位，最后 replace。报错形如 Expected a semicolon。
2. **python 里 io.open(p,'w').write(x) 求值顺序会先截断文件**：x 里抛异常（例如 NameError）就得到 0 字节文件。README 被这样清空过一次。先算好内容，再 open。
3. **监听叠加**：每次 render 都 addEventListener，点一次跑 N 遍（next() 越界、页面直接跳 summary）。一律用 host.onclick。practice.js 与 archive.js 各踩一次。
4. **视图注册必须 MC.router.view(name, def)**，写 MC.views 会静默回退到 today（#/weak 就这样假绿过）。
5. **字段名**：graph 的边是 s / d / r；节点是 id / volume_id / chapter_no / section_no。写成 src/dst/uid/vol/ch/sec 全是 undefined，且静默返回空集合。
6. **造断言的基线数据先清场**：残留记录会凑出「做过 2」的巧合，而册级累计不是 2。
7. **冒烟默认视口 430 宽（手机）**；量宽屏要自己 setDeviceMetricsOverride。同一个 hash 再 navigate 不触发重渲染，中间要插一次别的路由；**写完 localStorage 想重新量，用 `Page.reload`**，navigate 到当前同一个 URL 只会留一屏旧 DOM（2026-10-31 因此误判「种了数据却没进列表」，白查两轮）。
8. **中文路径 + 内联 python -c 会坏**（unexpected character after line continuation）；一律先写 .py，并加 PYTHONIOENCODING=utf-8（GBK 控制台打 · • 会 UnicodeEncodeError）。
9. **bash 正在执行的脚本不能改**：bash 按字节偏移增量读，改了会 line 31: tep: command not found。改完先 bash -n。
10. **跨行正则改前端会越过 }))); 边界误删后续函数**（diagnose/app.js 曾因此丢 4 个函数）。改为「先断言上下文行，再按 index 切片」。
11. **前端 clip() 会在截断处补一个「…」**，卡片宽度要按 (截断字数 + 1) 算，否则名字横穿相邻格子。
12. **Cy 的 width 支持 data() 映射**（聚合线按处数加粗靠这个）；但布局尺寸必须以 data(w)/data(h) 为准，LOD 改大就会重叠。
14. **种子数据可能和存量欠账是同一道题**，这时页面只会多出一行 —— 期望行数得按「并集」算，写成 `base + made` 就会假红。`retry` 的用例挑的是「册里第一节 + 最后一节」，而最后一节的题正是章末巩固题，前面几个交互用例早就把它们答错过。同理：断言「多了几条」只适合种子题一定不与存量重合的场景。
13. **flex / -webkit-box 容器会把公式拆散**。KaTeX 的输出是一层套一层的 span，容器的子元素一旦成为 flex item 或 box item 就被 blockify，公式变成「一行一个符号」的竖排块（实测 `x²=a(a≥0)` 撑到 144px 高、占满整行）。`-webkit-line-clamp` 尤其致命，因为它同时要求 `display:-webkit-box`。规矩：放 `mathHtml` 输出的容器只能是普通流；容器必须是 flex/grid 时，内容先包一层 `<span>`；`line-clamp` 只留给纯文本。判据是 `out/probe_blockify.js`（扫 .katex 的父容器 display，18 条路由应为 0）。

### 2026-11-03 图谱导航一致性 + 章级档三条硬缺陷（团队复核 P0/P1/P2）

**起因**：两份独立复核（`out/team/cmap-ux.md` 110 行、`out/team/cmap-qa.md` 128 行）都不约而同指向同一件事——图谱的「换档」与「地址栏」是两套状态，谁先谁后没有约定。加上我自己点的四次（`out/probe_clicks.js`，坐标要加 `#cy` 的 `getBoundingClientRect` 偏移，否则点了没反应）拿到的事实，本轮按四条改：

**一、地址栏跟着焦点走（导航一致性）**
- 点开一个知识点会进十字档，但 `location.hash` 不动。后果是三条：刷新回到章级档、练习页的「‹ 返回」回到总图而不是这个点、分享出去的链接丢了焦点。
- 改法：`crossUrl(id)` / `layerUrl()` 两个函数，`syncCross()` 里用 `history.replaceState` 单向同步——十字档开写 `#/map?node=<id>`，收写回 `layerUrl()`（只清 `node=`，保留 `vol/ch`）。用 replaceState 而不是 `router.go`，因为它不该触发一次重新渲染（那会把刚画好的焦点档打散）。
- 十字档「去练习」带上 `from`，练习页返回就回到这个点。
- 「回到总图」按档改名：章内档叫「回到这一章」——按钮名与它的实际作用必须一致（决策 39 的延伸）。

**二、P0：章间先修线只画 29/83**
- `buildChapterMap()` 拼章 id 用 `'C' + vol + '-' + ch`，而章节点 id 是 `C701-01`。`at[ka]` 查不到就 `return`，**静默**丢掉七年级两册 34 条出边（701:19 + 702:15）。

**三、P1：视口变了不重排形态**
- 720px 是「画布 / DOM 列表」的分界，两档 DOM 不同；而全站唯一的 `resize` 监听只做 `cy.resize() + fitView()`。1440 拖到 430 实测 `isList:false / zoom:0.375`——26 张章卡片留在画布上缩成 4.8px。
