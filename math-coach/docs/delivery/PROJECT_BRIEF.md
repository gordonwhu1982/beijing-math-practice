## 问题与机会

给一个使用北京版八年级上册（2024 版）的初二学生，做一套不联网的个人数学教辅：六册知识图谱、解题方法、错因和可练习的题。权威数据在 Git 文本里，前端是 `runtime/web/` 的静态页面。

## 产品目标与可量化结果

学生能按教材往下学、做题、看自己哪里不稳，并且每条知识关系和判题结论都能指回文件。数字以 `docs/STATE.md` 为准，本文件不复制会过期的计数。

## 用户与主要场景

当前使用者一名：初二学生，主线在八年级上册第 12 章（三角形），图谱覆盖 701 / 702 / 801 / 802 / 901 / 902。没有账号、没有后端。

### 本期包含

## 业务、技术和合规约束

- 调试期私有，仓库没有 remote，不推远端（`docs/STATE.md` §0）。
- 判不准的题显示「这题我判不了」，不得显示成错。
- `private/`、`out/`、`build/`、`runtime/web/data/` 不进仓（`.gitignore`）。
- 知识点与多数方法仍是 `ai_draft`，未经教研复核。
