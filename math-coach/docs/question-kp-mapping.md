# 题 → 知识点映射

诊断此前只能停在**节**：题库的 `topics` 只写到 `S801-12.1` 这一级，而一节里有 3–10 个知识点。
不落实到点，「这题考哪条」「薄弱在哪一步」都无从谈起。这份文档记录映射是怎么做的、
可信到什么程度、以及哪些题故意没做。

## 结论先看

| 项 | 实测 |
| --- | --- |
| 写回的题 | **2576 / 2708 = 95.1%**（ch10 427 / ch11 607 / ch12 1176 / ch13 366） |
| 覆盖的知识点 | 139 / 151（801 全册） |
| 进前端切片 | 2355 条（差额 221 条是缺答案、不排进练习队列的题） |
| 词表法那批的准确率（严格） | **25/29 = 86.2%**（半对不算对；在第 12 章 243 条里分层抽 40 条判的） |
| 词表法那批的准确率（宽松） | 29/29（同节相邻点算可用） |
| 逐节 AI 辅助那批 | 2333 条，**尚未抽检复核** |
| 故意留空 | 132 条：章内没有对应点的超纲题 + 答案本身空白的 err 题 |
| 审核状态 | 全部 `ai_draft`，未经教研复核 |

按这个口径，**只能拿来做「这题大概考什么」的提示与人工确认的候选，不能拿去做掌握度判定**。
掌握度要有意图地偏保守：宁可显示「这题考什么：未标」，也不要标错一个点让孩子去补错的东西。

## 做法

三个文件构成一条链，每一段都能单独重跑：

1. `tools/kp_terms.json` —— 第 12 章判别词表，169 条术语，覆盖 93/99 个知识点。
   每条术语带权重 `w` 和它指向的知识点（一个词可以挂多点，挂得多会按
   `1/(1+0.30*(n-1))` 衰减）。参数：`answer_weight 0.6`（答案里出现的算 0.6 份）、
   `ngram_weight 0.30`、`min_term_score 10`、`review_score 5`、`lead_ratio 1.6`、
   `skip_patterns ["_com_"]`。
2. `tools/questions_kp_map.py` —— 出 `build/questions/kp_map.jsonl`，每题带
   `kp[]`、命中的 `evidence`、top1 分 `top`、领先比 `lead` 与 `status`。
3. `tools/questions_kp_writeback.py` —— 只把 `status=auto` 的写成侧挂文件
   `content/questions/801/ch12.kp.jsonl`（与 `ch12.answer.jsonl` 同构）。
4. `tools/build_web.py` 把映射并进前端切片，练习页判完显示「这题考：…」。

### 三个设计决定

**候选取整章，不取本节。** 题库的 `section_no` 是分章批量编号，与内容常错位——
`12.1_bas_02`「第三边取值范围」实际是 12.2 的内容，`12.10_adv_10` 是倍长中线题。
按本节取候选，这些题直接变 `no_candidate`。改为整章候选后，本题所在节只作为一个
`1.5` 的弱先验加分。

**最长术语优先 + 位置遮蔽。** 命中「逆命题」之后把那段文字占住，「命题」不再重复计分；
「等腰三角形」吃掉「三角形」。不这么做，通用词（三角形、角、边）会全面压过判别词。
实现见 `questions_kp_map.py` 里 `used = bytearray(len(text))` 那一段。

**映射走侧挂文件，不改题库本体。** 题目本体是教材抽取 + 人工补答案的产物，
改一行就要重跑全套闸门；映射是派生结论，单独一个文件既能逐条 diff 评审，
也能整体删掉重算。

## 分级门槛

| status | 条件 | 条数 | 处置 |
| --- | --- | ---: | --- |
| `auto` | `top ≥ 10` 且 `lead ≥ 1.6` | 243 | 写回，标 `ai_draft` |
| `review_lead` | `top ≥ 10` 但领先不够 | 282 | 人工二选一 |
| `review` | `5 ≤ top < 10` | 415 | 人工判 |
| `weak` | `top < 5` | 190 | 判不了，留空 |
| `competition` | id 含 `_com_` | 150 | 一律不写回（竞赛题常超本章范围） |

`lead_ratio` 定在 1.6 是拿样本换出来的：降到 1.3 能多收 2 条对的，但也会放进
`12.12_adv_04` 这类「判锐直钝被判成按角分类」的半对题，不划算。

## 金标准怎么评的

从 auto 档分层抽 40 条，逐题人工判「top1 是不是这道题真正在考的点」，口径分三档：
对、半对（同节相邻点，如题面考外角而判成内角和）、错。

结果是 25 对 / 4 半对 / 1 错。那 1 条错的是 `12.6_int_08`——等腰求角被判成「高」，
因为题干里 `DE⊥AB`、「垂足为 E」比「等腰」更显眼。把「等腰」权重 6→7、「垂足」7→5
之后它降为 `review`，auto 档里判错归零。**这类修正本质上是在调词表的注意力，
不是在改进算法**，所以词表每加一个词都要重跑一遍抽样。

## 天花板在哪

词表法在两类题上必输：

- **题干数字密集、方法靠答案算**：给三边判锐角/直角/钝角，真正考的是「比较最长边平方
  与另两边平方和」，而题干里只有三个数字，词表只能抓到「三角形」「三边」。
- **同一题同时用到三四个点**：直角三角形里中线、角平分线、高齐出（`12.3_adv_04`），
  单点 primary 本来就是错的抽象，这类题应该允许多点并列。

因此不追全覆盖，只收高置信。剩下的 1037 题按上表分档进人工确认队列——
人工确认的成本远低于标错一个点带来的连锁误判。

## 第二轮：逐节 AI 辅助标注（2026-10-28）

词表法在第 12 章能到 86.2%，但它对「题里的术语是用到了而不是考了」无解，扩到别章就会掉准。
四条自动路都试过并放弃：全库别名子串吻合率 55.1%、节内唯一术语法 precision 68.0% / 覆盖 20.6%、
2-gram 匹配把「用勾股定理求边长」判到点内顺序错的位置、LCS 判据跨节错点。
所以第二轮不再调规则，改成**逐题读一遍，判不准就留空**：

1. `tools/questions_kp_task_split.py` 按节拆包：每包只给本节候选点（3–10 个），题按 `section_no` 分组，章末综合归 chapter 包。
2. 逐包标注，输出侧挂格式（`kp_tags` 里恰好 1 个 primary，第二个只能 secondary 0.5），`basis.evidence` 必须引题干或答案原文。
3. `out/kp_task_leftover.py` 把判不准而留空的题重新打包——这次候选点放宽到**全章**。教材习题常跨节引用：12.7（直角三角形）那节 74 题里有 60 题的答案核心是勾股计算，而勾股点属 12.11。放宽后这批能救回 165 题。
4. `out/kp_lint.py` 自检（点存在 / 恰好一个 primary / weight>0 / 题号真实 / 不重复），`out/kp_merge.py` 幂等合并（已有 uid 不覆盖），`tools/questions_kp_check.py` 在闸门里再核一遍。

**留空的 132 题不是失败，是结论**：中位线（16 道）、斜边上的中线、30° 角所对边 = 斜边一半、
海伦/塞瓦/梅涅劳斯、角平分线定理、费马点旋转、坐标斜率求最值、黄金分割、比例中项、模 3 数论、
面积公式 ½底×高，这些点在这册教材里没有（中位线在 802 八下），属超纲；另有 7 道 `err` 题答案本身空白。
按「宁可显示未标，也不标错一个点让孩子补错东西」的口径，这些题就该留空——
前端的四行卡在这类题上给节级兜底，并写明「整节共通，不是这题专考」。

一条操作上的教训：合并脚本最初吃整个目录，把 ch10 的 187 行同时写进了 ch11 和 ch13 的侧挂文件
（三个文件都变成 318+187 / 549+187 / 346+187）。修法是 `--src` 既接受目录也接受单个文件，
用它之前先 `wc -l` 看一眼要合并的是哪几个文件。

## 抽检（2026-10-28）：48 题随机抽样，严格吻合 77.1%

之前这条链一直挂着一句「尚未抽检复核」。这次抽了 48 题（每章 12 题，随机种子 20261028），
逐题看题干与挂点，结论如下。

| 判定 | 题数 | 含义 |
| --- | --- | --- |
| 对 | 37（77.1%） | 主挂点就是这题真正在考的那一步 |
| 偏 | 4（8.3%） | 主挂点方向相关但不是核心（如求中线长挂「中线的定义」而非三线合一+勾股） |
| 错 | 7（14.6%） | 主挂点与这题考的东西不是一回事 |

按章：第 10 章 10/12、第 11 章 8/12、第 12 章 9/12、第 13 章 10/12。

### 两种错误模式（比数字更有用）

1. **被表面名词带走**。题面出现了某个名词，就挂到那个名词对应的点上，而不是挂到解题真正动用的那一步：
   - 10.5_cha_09「已知 a+b+c=0，求 (a²+b²+c²)/(ab+bc+ca)」挂到「约分」——实际靠整体代入化成 -2；
   - 10.5_cha_06「a+b=1，求 1/a+4/b 最小值」挂到「分式乘法」——实际是异分母相加后化简求最值；
   - 11.7_cha_03「解 2√(x²+5x+1)-√(x²+5x-2)=3」挂到「平方根定义」——实际是换元 + 二次根式运算；
   - 11.1_adv_02「证明 √2+√3<√10」挂到「算术平方根」——实际是比较大小用平方法。
2. **同节相邻点错位，且没有跨节视野**：
   - 12.3_cha_09「三条高交于 H，求 ∠BHC」挂到「三条高的位置」——求角用的是外角与内角和，在同节的相邻点里挑了一个看起来最像的；
   - 13.1_int_20「抛硬币连续 5 次正面，第 6 次一定是反面？」挂到 13.3 的「概率公式」——问的是必然事件与随机事件的观念，本该留在 13.1，跨节选错了。

### 口径

77.1% 严格吻合意味着：四行卡的「先得会」「做法」方向上大致对，但**约 1/7 的题会指到相邻的错误点上**。
够当提示，不够当诊断依据——掌握度不能拿它算，这也是面板里一直写「按方法推断」而不是「你的薄弱点」的原因。
要再往上，只能把每节候选点之间的差别写成人可读的判据（例如「考的是定义还是变形式」），
这已经不是加一轮 AI 标注能解决的。

## 复现与校验

```bash
python tools/questions_kp_map.py                 # 重算映射
python tools/questions_kp_map.py --explain 12.1_bas_10   # 看单题命中明细
python tools/questions_kp_writeback.py --dry-run # 只看统计
python tools/questions_kp_writeback.py           # 写侧挂文件
python tools/questions_kp_check.py               # 校验（已进 check_all.sh）
```

`questions_kp_check.py` 拦四类错：题号在题库里找不到、`kp_uid` 在框架里找不到、
一道题不是恰有一个 `primary`、缺 `weight`/`review_status`。它还会数一遍前端切片里
实际落了多少条——映射写回了、前端却拿不到，等于没做。
