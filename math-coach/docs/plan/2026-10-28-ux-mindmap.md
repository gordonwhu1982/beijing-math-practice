## 2. 为什么上一张图失败

2026-10-28 对着正在跑的页面看过：

- 全景：54 个点、7 座岛、204 条紫线。章名被截短，思想线穿过所有册。
- 章图（八年级上册第 12 章）：99 个点、12 座岛、183 条线。节名是横条，知识点是小胶囊，页面自己写着「字有点小了」。
- 首页把目录、图谱、思想、哪里不稳、依据总览、档案、八年级上册摆成同等的七张卡片。

竞品（奕思 Geek&Chalk，见 `docs/ref/2026-10-27-kg-mobile/m01-global-thoughts.jpg`）不是仪表盘。它是一张导图：上面是大标题，知识是一片点，线只在当前这一支上，讲解在旁边。940 个点能看，是因为远看是点，不是因为把卡片缩到 7px。

开源里值得学的是交互，不是他们的数据，也不用力导向（第二次打开位置会变）：

- [Knogra](https://github.com/jchen1/knogra)：一次只看一个场景，思维导图可折叠。
- [Marble Taxonomy Explorer](https://github.com/allenai/marble)：探索时只展开先修链大约三层，不摊开全图。
- [OKVE](https://github.com/okve)：放射树。我们借「从根向右长」这一笔，不借它的库。

## 3. 画面规则（对照 docs/ref 的原图）

- `t01-global-graph.jpg`：全局是细线织成的网，点是小菱形，章名浮在点团上。不是色块方阵。
- `t02-dashboard-filters.jpg`、`t03-chapter-tree.jpg`：另一屏是四列，素养 → 教材 → 章节 → 知识，点章节才在右边列出知识点。
- `t08-local-graph-pre-post.jpg`、`m02-kp-detail-standard.jpg`：点一个点，图留在原地，卡片上写前置 → 当前 → 后续。

## 3b. 原先的画面规则

对照 `docs/ref` 里奕思的「全课程知识网络」，以及用户 16:58 发来的同一张截图：

1. 打开 `#/map` 看到六册，不是一章。知识点是色点，不是大框。章名标在点团上。六条思想在上方，画成三角。
2. 章和章之间有线：同册前后章一条，跨章「先得会」聚成章与章的连线。思想到章是更淡的线。知识点之间的先修不默认铺满，点中一个点才画出它往上三步「从哪里长出来」。
3. 讲解不占右栏。点一个点，卡片浮在图谱上，图的宽度不变。点空白处收起。
4. 旧画法留在「其他画法」里。不要加新的主导航，不要力导向。

## 4. 成功时的样子

一屏能看见六册的点团和章名，以及跨章的线。点一个点，这个点变大，先修链亮起来，说明浮在图上，底下的点还在。
