## 3. 表 B：线的实测（本轮最硬的一条）

选中 K701-1.1-01 后逐边取样式（out/ux4b_expr_opacity2.js，清 localStorage 后重跑两次同值）：

| 指标 | 实测值 |
|---|---|
| 总边数 | 3698 |
| 可见边（`+e.style('opacity') > 0.05`） | **3698（全部）** |
| opacity 直方图 | `{0.12: 3691, 0.95: 7}` |
| 非焦点边 class | `dim e-x mind-dim` |
| `e.style('opacity')` | **0.12** |
| `e.renderedStyle('opacity')` | **0.196** |
| `e.visible()` | true |
| 清掉选中后（点空白） | `sel=0`，但 `en=0 / ex=3691`，可见边 **7** |

三个规则在打架，都在 `runtime/web/js/views/map.js`：

```
map.js:2440  { selector: 'edge.e-x',      style: { 'opacity': 0    } }
map.js:2445  { selector: 'edge.dim',      style: { 'opacity': 0.22 } }
map.js:2616  { selector: 'edge.mind-dim', style: { 'opacity': 0.12 } }   ← 后定义、同特异性，胜出
map.js:2627  { selector: 'edge.mind-dim', style: { 'opacity': 0.12 } }   ← 同上
```

`mind-dim` 是被 map.js:1526/1532/1634/1641/1731/1819 六处 `addClass` 加上去的，而 `clearMarks()`（map.js:2766-2770）只 `removeClass('dim sel nb')`，**从不清 `mind-dim`** → 一旦进过局部环，这个 class 永久残留。

所以 lead 在 `focusNode`（map.js:2772-2794）里写的「其余所有边 → removeClass('e-f e-n e-x') addClass('e-x')」**逻辑正确，样式层被覆盖**。注释原话「整张网里剩下的线全部不画」在代码上成立、在渲染上不成立。

**修法（二选一，都只动样式层）**
- 小改：把 map.js:2616 与 map.js:2627 的 `'opacity': 0.12` 改成 `0.02`（比底纹 0.15 低一个数量级，肉眼即「没画」）。
- 正改：在 style 数组**最末尾**追加 `{ selector: 'edge.e-x', style: { 'opacity': 0 } }`（同特异性后者胜），并在 `clearMarks()` 的 removeClass 里补 `mind-dim`。

**第二个 bug（与上面独立）**：点空白的 `releaseFocus()` 分支（map.js:4878-4885）只清选中，**不调 `restEdges()`**，3691 条边留成 `e-x`（opacity 0）→ 底纹 `e-n: 0.15` 回不来，画布变成「一堆没有线的散点」（截图 ux4b_t03_blank.png，可见边 3698→7）。只有重新进页面（`en 3698`）才恢复。修法：`releaseFocus()` 末尾补 `restEdges(); clearMarks();`。

## 5. 判题三态实测（manual 红线：正反两面）

**正面（红线守住了）**：填「1」交卷后页面写「**这题我判不了**」「需要你确认」「参考答案和你写的不完全一样，但我不敢替你判错。你看一眼：」，给的是「我做对了 / 我做错了」两个平级按钮 —— **没有红叉、没有「错」字、没进错题**。`#/archive` 也写「判不了的那些不走进错题，也不会拉低会做率」。符合设计。

**反面（自评 = 掌握）**：`data-act="self" data-v="correct"`（practice.js:424-425）点一次，命中三处口径：

| 位置 | 点之前 | 点 4 次之后 |
|---|---|---|
| 结算 | 0 做对 / 2 没做对 / 4 判不了 | **4 做对** / 2 没做对 / 0 没做，且多出「**已掌握 · 4 道**」 |
| 目录 801 | — | 「独立做对 **4**」 |
| 档案 | — | 会做率 **67%**，「自动判 2」 |

`#/toc` 页首句写着「带提示做对的不算独立做对」，却把自评算成了独立通过。旧引擎的 74% 推断放大，换了个入口又长出来。

判题覆盖：12.1 前 6 道「基础」题里 4 道判不了（66.7%），判得出的 2 道我故意填 1 判错。这与 `#/weak` 页脚「题到知识点 2576 / 2708（95.1%）」不矛盾 —— 映射在，但 `answer_spec` 判不出多答案/文字作答。

## 7. 需要 lead 决策的三件事

1. **样式层先修还是合修**：§3 两条都是 3 行内改动（map.js:2616/2627 数值 + `clearMarks` 补 removeClass + `releaseFocus` 补 restEdges）。建议一起改，改完复跑 `out/ux4b_map2.js`，判据：选中时 `visEdges` 应 = 7；清空后应 = 3698 且 `en` 全 3698。
2. **「导图」按钮**：map.js:4793 的分支要求清 `state.lens`，点「导图」（map.js:4510-4512）时没清。建议在 data-view 处理里加 `state.lens='web'`。
3. **「自评 ≠ 独立通过」**：结算 / 目录 / 档案三处口径要统一；`data-v="correct"` 应进「自己说要算对」一档，不该叫「独立做对」、不该计入「已掌握」。
