## 0. 结论先行：7 个实测数字逼出 7 条界面硬约束

| # | 实测（口径） | 界面后果（不许商量的） |
|---|---|---|
| 1 | `figure.figure_ids` 为空的题 **1047/1128**，其中 `figure.need=required` **466**、`helpful` **581** | 全局不设「图片占位框」。need=required 且无图时（466 题）题面下方固定一行「原题有图，本机没存」，配一个「我在纸上画好了」的确认按钮，否则几何题（proof 292 + construction 72 = **364 道**）孩子一打开就卡住 |
| 2 | `answer_steps_declared=0` 的题 **567/1128**；其中 basic **274/297（92.3%）**、standard **207/295（70.2%）**、advanced 79/200、challenge 2/171 | **分步折叠只在 band ≥ advanced 出现**。basic/standard 592 道题没有可折叠的步骤，屏上就只能是「整段解析 + 结论行置顶」，不许出现空的步骤条 |
| 3 | rubric 覆盖率按 band：basic **16/297（5.4%）**、standard 84/295、advanced 117/200、challenge 169/171、competition 160/165 | 「分步自评 / 分步得分」不是主交互，是 band ≥ advanced 的加值能力。基础题结算页不许出现评分进度环 |
| 4 | `form=choice` **17 道，但题目里没有 options 字段**（题干只留「（ ）」） | 全站不渲染 A/B/C/D 按钮。这 17 道在派题时一律降级为「手写答案 + 自评/家长判」，即 verdict 只能 correct/manual/wrong 手选 |
| 5 | 每题 `topics` 长度恒为 1 且 `topics_scheme=section`，`kp_tags` 填充率 0%；`section_no=null` **107 道**（章级题） | 练习的最小单位只能是「**节**」（S801-12.x），今日屏不许写「练这个知识点」。107 道章级题必须单独挂「章末综合」入口，不混进按节派题 |
| 6 | `answer_note` 为空 **602/1128（53.4%）** | L3「方法族」提示只有 526 道有素材。提示阶梯第 3 级命中率不足时，第 4 级直接给「第一步」，不许空着弹一个空壳提示 |
| 7 | `answer` 长度 p50 **246** 字符 / p90 **723** / max **2151**；含「步骤N」标记 **561** 题 | 解析区默认折叠到「结论 + 前两步」，先给 3 行，点「展开全过程」再出全文。<200 字符的（p50 以下）不折叠，直接铺开，少一次点击 |

另：`enums.verdict` 是四值 `correct/wrong/manual/blank`，契约里已经有第 4 态。**blank（超时/跳过/未提交）在界面上不等于 wrong**，不进错题本、不降掌握度——这是本文与题面「三态」说法的唯一补充。

## 1. 主流程分屏：打开 → 15 分钟 → 关掉

统一兜底规矩（适用于全部 8 屏，逐屏不再重复）：

- **首屏不依赖任何异步数据**：index 页 HTML 内联「今天第 12 章 · 12.4」这行字，切片 `build/slices/801.public.json.gz` 实测 0.03MB gzip，`<script type="module">` 同步 import，无骨架屏。
- **任何超过 1 秒的操作必须先出结果再补细节**：判题是纯本地函数，永远瞬时；解析分两段，先出 shell 后填 body。
- **不用 loading 圈**。用三种可见状态代替：①已渲染但未算完（占位是真实文案，如「步骤 2/6」）②降级态（能力关掉的控件直接不出现，见 §1.0）③失败态（一句话 + 一个主按钮，见 §1.9 表）。
- **预取**：练屏在 idle 时预取下一题（判定后用 `requestIdleCallback` 载下一题与 rubric），「下一题」按钮永不等待 IO。

### 1.0 能力开关表（前端按 manifest.capabilities 隐藏控件，不猜字段）

capability 名取自 `schema.json .capabilities.list`（9 项），右列为第 12 章现状与界面动作：

| capability | 现状（实测） | 界面动作 |
|---|---|---|
| `knowledge_page` | 143 节齐，但 `definition` 0%、574 点 title_only | 节页只显示「节标题 + 教材页码 + 本节题量（83~91 题）」，不显示空的「定义」区块 |
| `practice` | 1128 题 | 开 |
| `hint_ladder` | L1/L2 可从题面与节标题生成；L3 仅 526 题有 answer_note | 开，但 L3 按钮在这 602 道上隐藏，直接跳 L4 |
| `rubric` | 546/1128 | 仅 band ≥ advanced 显示分步盘；basic 16/297 时即使有也不显示 |
| `figure` | 1047 题无图 | **关**。need=required 的 466 题走「纸上画」确认按钮 |
| `method_hint` | `skill` 实体 0 条 | 关（L3 走 answer_note 兜底，不走 skill 实体） |
| `misconception_diagnosis` | `misconception` 实体 0 条 | 关。错因只能手选 8 类枚举，不能「自动诊断你错在哪」 |

### S0 今日（打开即看到的唯一一屏）

- **意图**：3 秒内知道「今天干什么、大约多久」，不给他选择负担。
- **主控件**（自上而下）：
  1. 一行大字：「今天练 12.4 三角形全等的判定 · 6 题 · 约 15 分钟」——节由 review_plan 现算（不建实体，v3 §14-6），题量固定 6。
  2. 主按钮「开始」（`btn-primary`，宽 100%，拇指可达区）。
  3. 次按钮「换一节」（进入 S1）。
  4. 底部一行灰字：「昨天 12.3 有 1 题没做完」→ 点它直接进那题（`feedback_debt`），这是把「补」做成入口而非屏。
- **首屏必有**：上面三处文案全部内联，不读切片。
- **兜底**：①节页题量不足（如某节 81~91 题够，但若未来某节 0 题）→ 今日屏改显「这一节还没有题，先去练 12.1」，按钮直接切节，不出空态页。②review_plan 算不出（evidence 为 0，第一天）→ 规则兜底「从 12.1 开始，6 题 basic」，永不空。

### S1 选路（练 / 测两条通道，规格 §5 的硬要求）

- **意图**：advanced 实测 0/277 可达，所以「培优」必须自己有一条入口，不能藏在难度滑杆里。
- **主控件**：两张并排大卡（不是下拉框）：
  - 「跟着课本练」（basic/standard，按节）
  - 「往上够一够」（advanced/challenge/competition，实测 536 题：200+171+165）
  - 底部小字：「章末综合（107 题）」
- **兜底**：卡上直接写题量与平均用时（用时取上次同类题的 `seconds` 中位数，无数据则写「约 15 分钟」），不写「智能推荐」。

### S2 练中·题面（15 分钟里停留最久的一屏）

- **意图**：题面 + 输入 + 三级工具（提示 / 跳过 / 交卷），一屏一题，不滚动超过一个屏高（题干 p90 140 字符，一屏放得下）。
- **主控件**：
  - 顶栏：`12.4 · 第 3/6 题` + 右侧倒计时胶囊「还剩 9:12」（到 0 不中断，见 S5）。
  - 题干区（KaTeX 行内渲染；卡片 `max-width: 680px`）。
  - 无图降级条（见 §0-1）：466 题出现，一个 checkbox「我在纸上画好了」。
  - 作答区：单行 textarea（`inputmode="text"`，支持 `^` `/` 快捷插入上标与分数）+ 拍照按钮（本地压缩后存 private，M4a 前只本地）。
  - 底部固定工具条三个平级按钮：`提示`（L1）｜`跳过`（verdict=blank）｜`交卷`（primary）。
- **兜底**：①KaTeX 渲染失败（本地 23990 个式子 0 错，但新题可能有）→ 该公式降级为等宽纯文本 + 右上角一个 `TEX` 小标签，不显示 `$...$` 原文。②题干含「$」但渲染器没加载 → 先纯文本渲染，绝不空白。③同一题连续两次提交失败 → 直接进 S3 的 manual 分支。

### S3 练中·判题三态（详见 §2）

- **意图**：告诉他「对/不对/我判不了」，错的时候**先不给答案**，先登记错因。
- **主控件**：顶部一条 48px 高的结果条（色 + 一句 8 字以内文案），下面接 8 个错因 chip（仅 wrong 时）或 2 个自评按钮（仅 manual 时）；答案与解析**在错因登记后才展开**。
- **兜底**：判题函数抛错 → 直接落 manual 分支，文案「这题我先判不了」，绝不假判 wrong（契约 `judge` 的 manual 优先于 wrong）。

### S4 提示阶梯（覆盖层，不是独立屏）

- **意图**：逐级给，每级一次点击，用了就记账。
- **主控件**：底部抽屉，4 格（L1 重述 / L2 定位 / L3 方法 / L4 第一步），已用的格变实心且标「已用 L2」；L3 在 answer_note 空的 602 道上不出现；抽屉里始终有一个「直接看全过程」（`full_solution`，最贵的记录，用后该题不计入掌握）。
- **兜底**：某一级没素材 → 该格直接不渲染，不留灰格（灰格会被点开成空）。

### S5 结算（15 分钟到点 / 6 题做完）

- **意图**：3 秒看完本次成绩，给他「今天够了」的收束感，然后关掉。
- **主控件**：
  - 一行统计：「6 题：独立 4 · 带提示 1 · 我判不了 1」
  - 三个次级块（都可折叠，默认收起）：`待巩固 1` / `下次再试 1` / `今天没做的`（blank）
  - 主按钮「今天就到这儿」（primary），次按钮「再做 2 题」。
- **兜底**：`seconds` 累积 <60 秒（误触进入）不写结算、不写 evidence，直接回 S0。

### S6 补学出口（从错题进，一步到底）

- **意图**：修掉「诊断完没有补学出口」。出口只能有**一条**，不许给列表选。
- **主控件**（依序，按可用性降级，永不空白）：
  1. 节页锚点：「回看 12.4 · 教材第 78 页」（673/673 点有页码）
  2. 一条方法提示（answer_note，526 题有；无则跳过这层，不留空）
  3. 「同一节·同一难度·再试 1 题」主按钮（真的换题，不是重做原题）
- **兜底**：该节 0 题可换（当前 12 节各 81~91 题，风险低）→ 退回 S0 并把该节标记「这节题做完了」。

### S7 档案（家长与孩子分两块，孩子默认折叠）

- **意图**：孩子看到「我今天有没有过」，家长看到「五态分布 + 撤销推断」。
- **主控件**：掌握度五态卡片墙（详见 §3）、右上角「⋯」菜单（含「我不认这个推断」）。
- **兜底**：evidence 为 0 → 显示一屏「还没有记录，今天练 6 题就有了」+ 回 S0 的按钮，不是空白图。

### 1.9 失败态总表（每种失败给唯一成句的出口）

| 失败 | 屏上写什么（≤16 字） | 主按钮 |
|---|---|---|
| 切片缺失/版本不符 | 内容包没找到 | 重新载入 |
| manifest.hash 校验失败 | 内容包是旧的 | 重新载入 |
| KaTeX 渲染失败 | 公式显示为文字 | （无，自动） |
| 题目无图但 need=required | 原题有图，本机没存 | 我在纸上画好了 |
| 判题异常 | 这题我先判不了 | 我自己看过了 |
| 本地存储写满（outbox） | 记录存不下，先停下 | 导出今天的记录 |
| 找不到下一题 | 这一节练完了 | 换一节 |

## 2. 判题三态（实际四态）与提示留痕

### 2.1 三态在界面上的差异（`enums.verdict` = correct / wrong / manual / blank）

| 立场 | 视觉 | 一句话文案 | 后续动作 | 数据后果 |
|---|---|---|---|---|
| **correct** | 左侧 3px 绿边 + 结果条浅绿底 + 一个「✓ 对」 | 「对」 | 800ms 后自动浮出「下一题」（不强制点） | `verdict=correct`；若 `hint_level=none` 记 direct，否则记带提示 |
| **wrong** | 左侧 3px 琥珀边（**不是红**）+「再想想」 | 「这步不对」 | 先出 8 个错因 chip（可跳过），登记后才展开答案 | `verdict=wrong`；错题本 +1；连续 2 次 → 该节标「不稳」 |
| **manual** | 左侧 3px 灰蓝边 + 无对错图标，只有一个「？」 | 「这题我判不了」 | 两个平级按钮「我做对了」「我做错了」；家长在旁则第三个「家长来看」 | `verdict=manual`；**不进错题本、不降掌握、不计正确率**；点了自评后转 correct/wrong 但保留 `how=manual` |
| **blank** | 无颜色，题面回到原样 | 「先跳过」 | 直接下一题 | `verdict=blank`；**不算错**，只进结算的「今天没做的」 |

**manual 的红线（写成验收项）**：界面任何位置不得出现 —— 红叉、`错题 +1`、`正确率下降`、把 manual 计入 `wrong` 的分母、以及任何「你错了」措辞。检查点：结算页分子分母必须是 `correct / (correct+wrong)`，manual 与 blank 都不进分母。

### 2.2 提示留痕：L1–L4 用了之后怎么记账

`enums.hint_level` = `none / L1_restate / L2_locate / L3_method / L4_first_step / full_solution`，每级**只记最高级**（同一题用了 L1 再点 L3，记 L3），写进 `learner_evidence.hint_level`，并保留 `hint_path` 数组在 `ext` 里（`x-hint-path:["L1","L3"]`）。

| 级别 | 素材来源（实测） | 该题判对后的记账 | 对掌握度的影响 |
|---|---|---|---|
| none | 题面 | **独立通过** | 计入 direct，可升「独立通过 / 稳」 |
| L1_restate | 题面重排（全部 1128 题可生成） | 带提示通过（弱） | 计入 direct 但 `evidence_count` 折半权，不进「稳」 |
| L2_locate | 节标题 + 教材页码（143 节全有） | 带提示通过（弱） | 同上 |
| L3_method | `answer_note`（**526/1128**，空 602 道不提供此级） | **带提示通过** | 不计实测掌握（规格 §5：L3/L4 做对不计实测掌握） |
| L4_first_step | `answer` 首句（1128 题可切） | **带提示通过** | 不计实测掌握 |
| full_solution | 整段 `answer`（p50 246 字符，先出 3 行） | 记为「看过答案」 | 该题只写 evidence，不产出任何掌握度证据 |

界面痕迹：题号右侧 4 个 4px 小圆点（已用级别点亮），结算页逐题一行「第 3 题 · L2 · 带提示通过」。「带提示通过」的题在结算里进 `待巩固`，**不进** `已掌握`——这两块在 S5 是两个不同的折叠块，不许合并成一个「做对了」。

## 3. 掌握度五态：视觉、文案、以及「我不认」

掌握度是视图不是字段（v3 §14-2：唯一入口 `tools/mastery_view.py:compute(evidence_rows, mastery_spec)`），所以下面每态都给**判定条件写进 `mastery_spec.json` 的具体键**，屏上只读不自己算。

| 态 | 判定（mastery_spec 键） | 视觉 | 卡片文案（≤10 字） | 进复习队列 | 可撤销 |
|---|---|---|---|---|---|
| **独立通过** | `src=direct` 且最近 `hint_level=none` 且 `verdict=correct` 且 `evidence_count>=3` | 深绿实心圆 100% | 「自己会了」 | 是（长间隔） | 否 |
| **带提示通过** | 有 `correct` 但 `hint_level ∈ L1..full_solution` | 绿描边空心圆 60% | 「提示后做对」 | 是（短间隔） | 否 |
| **推断** | `src=inferred`（由先修/子点传播，旧引擎实测 74% 是这样来的） | 灰蓝虚线圆 + 右上角一个 `i` | 「猜的，没做过」 | 否 | **是** |
| **不稳** | `direct` 但 `evidence_count<3`，或 `last_seen` 超出 `decay_window`，或最近 2 次含 `wrong` | 琥珀半环 + 波形图标 | 「上次会，现在悬」 | 是（明天） | 否 |
| **薄弱** | 连续 `wrong>=2` 或 该点 rubric 得分 <60%（546 题有 rubric 时才可算） | 浅红描边 + 缺口环 | 「这块得回去补」 | 是（今天内） | 否 |

修饰位（不占主态，卡片右下角小字）：`最近一次 3 天前` ／ `证据 2 条`。证据不足时宁可不显示数字，不显示「0」。

### 「我不认这个推断」入口

- **位置**：只有「推断」态卡片才有。卡片右上角 `⋯` → 菜单首项「这不是我」；同时 S5 结算页「这次估的掌握」区块里，推断条目右侧给一个行内文字按钮「这不是我」。
- **不放在**：主流程 S0–S4 的任何位置（孩子正在做题时不该出现元数据操作），也不做悬浮按钮。
- **点击之后**（逐步）：
  1. 底部滑出一条 44px 高确认条（不用弹窗）：「这条是按别的知识点推的，撤掉后要自己做过才算。」两个按钮：`撤销推断` / `算了`。
  2. 确认 → 写一条 evidence（不改历史，符合 append-only）：`{"uid":"EV-...","item_uid":"K801-12.4-03","verdict":"manual","how":"manual","ext":{"x-dispute":"mastery_inferred","x-disputed_at":"..."}}`。
  3. `mastery_view.compute` 侧：`mastery_spec` 增一条规则 —— 该 topic 存在 `x-dispute` 时，其 `src=inferred` 证据权重置 0，主态直接变「未验证」并**移出复习队列**。
  4. 卡片立即变灰 + 文案「已撤销，等你做过」（就地重渲染，无请求）。
  5. 30 秒内出现「撤销这个撤销」，点回即写第二条 `x-dispute: null` 的记录恢复。

## 4. 可直接用的中文文案（8 条，短）

1. 主按钮（S0）：「开始练 · 6 题」
2. 提示按钮（S2）：「提示」（第二级起自动变「再给一点」）

4. wrong 错因块标题（S3）：「哪一步没走通？」（下面是 8 个 chip，允许跳过）

## 5. 明确不做（8 条）

1. **不做选择题四选一界面**：17 道 `form=choice` 没有 options 字段，渲染 A/B/C/D 就是伪造数据；一律走手写答案 + 自评。
2. **不做「练这个知识点」粒度**：`kp_tags` 0%、`topics` 恒为 1 且是 section，最小单位只能是节；点级练习等 P1 的 kp_tags 到位再开。
3. **不做全局搜索框**：旧引擎「搜圆命中一年级认识圆、搜中考命中 0」的根因没修（`alias` 实体 0 条），做一个搜不好的框比没有更伤信任。
4. **不做加载动画 / 骨架屏 / 进度转圈**：切片 0.03MB gzip 全本地，转圈只是掩盖设计缺陷；一切等待用「真实文案占位」表达。
5. **不做红叉与正确率排行榜式仪表**：manual/blank 不参与任何分母，红色只用于「薄弱」态，不用于单题反馈。
6. **不做知识点定义编辑 / 富文本编辑器**：574 点 title_only 要补是 P3 的脚本活，界面里的编辑入口会被误用成第二权威。
7. **不做多孩子 / 家长账号切换 / 云同步按钮**：M4a 未上线，导出按钮先不出现；一个学习者假名 ID 够了。
8. **不做错题本无限累积**：错题只保留「下次再试」队列（≤10 题），超出的滚进节级「不稳」标记——错题库一旦变长，孩子就再也不打开它。

## 6. 反向需求：这份 UX 对 P1/P4 的 5 条硬要求

| # | 要求 | 落到哪个字段 | 为什么（数据支撑） |
|---|---|---|---|
