## 一、完整性拆成四个维度

"框架完整"不是一句话，它至少是四件互相独立的事。混在一起谈就会反复出现"感觉还缺东西"却说不清缺什么。

| 维度 | 回答的问题 | 当前判定依据 |
| --- | --- | --- |
| 结构 | 六册的章、节、知识点是不是都在？有没有空洞？ | `content/framework/volumes/*.json` + `knowledge_points/*.json` |
| 依赖 | 两个知识点之间谁先谁后，有没有断链和环？ | 节级 `prerequisites.json`、知识点级 `kp_prerequisites.json` |
| 支撑 | 每个知识点有没有定义、解题方法、典型错因？ | `knowledge_points/*.detail.jsonl`、`skills/`、`misconceptions/` |
| 版次 | 章节编排是不是对应孩子手上那一版教材？ | `volumes/*.json` 的 `edition.revision` + `verified` |

### 支撑：八上四章全齐，五册仍为空

| 实体 | 数量 | 覆盖范围 |
| --- | ---: | --- |
| 知识点定义 detail | 673 | 六册全覆盖 |
| 解题方法 skill | 125 | 八上第 10–13 章全 27 节（每节 2–8 条）。按 `tier` 分三层：教材内 **83** / 培优 **28** / 竞赛·拓展 **14** |
| 错因 misconception | 127 | 同上（每节 3–7 条） |
| applies_to 边 | 356 | 方法→知识点 |
| misconception_of 边 | 254 | 错因→知识点，双向引用 0 处断裂 |

三层方法的分工（`skill.tier`）：
- **core（教材内标准方法）83 条**：教材正文里出现的方法，如「求分式有意义的条件」「用 SSS 证全等」，steps 的 basis 直接对应教材定理。
- **extend（培优 28 条）**：教材不讲、但用本册知识就能解的常用方法，如角平分线遇平行线得等腰、等面积法求点到直线的距离、将军饮马变式、特殊角三角形三边比。`ext.curriculum_distance = small-gap`。
- **olympiad（竞赛·拓展 14 条）**：需要教材外结论或超前知识，如截长补短、手拉手模型、半角模型、一线三等角、双重根号化简、裂项相消、角平分线分对边成比例、反证法证 $\sqrt2$ 是无理数。`ext.curriculum_distance = beyond`。

判断一个方法该进哪层，用三条依据：① 教材正文有没有讲（有 → core）；② 只用本册知识点能否说清每一步的依据（能 → extend，不能 → olympiad）；③ 是否依赖教材外结论（依赖 → olympiad）。`family` 把同族方法归到一起（「全等模型」「整体代换」「非负性」等），提示阶梯 L3 上做同族置换要靠它。

八上四章的分布：第 10 章（分式）23 方法 / 21 错因、第 11 章（实数与二次根式）27 / 27、第 12 章（三角形）64 / 64、第 13 章（事件与可能性）11 / 15。八上 151 个知识点里，每个点至少挂上一条方法或一条错因。

**这批扩展方法最需要教研把关**：教材里没有原文可对，依据只能来自培优班与竞赛的通行讲法，`review_status` 一律 `ai_draft`。

五册 522 个点仍然方法 0、错因 0。这不再受版次阻塞（方法与错因挂的是知识点，不挂章节编号），但要按册做教材内容核对后才不会写错——下一批建议从 802 二次根式与勾股定理的延伸、901 一元二次方程与相似入手，优先覆盖与八上衔接最紧的点。
