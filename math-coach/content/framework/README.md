# 北京版初中数学 · 教材框架数据（content/framework）

本目录是 math-coach 的**整初中骨架**：六册 → 章 → 单元 → 节 → 知识点。
目标不是"够用"，而是**完整且可核对**——每一行都能指回"哪一册哪一个 PDF 的第几页"。

## 文件

| 文件 | 作用 |
|---|---|
| `volumes/<volume_id>.json` | 一册的章/单元/节/辅栏（探究学习、阅读理解、回顾与整理、复习题）目录，带起始页码与来源 PDF 的 sha1 |
| `knowledge_points/<volume_id>.json` | 该册知识点（挂在节下），带 `review_status` |
| `../../tools/framework_gen.py` | 由上面两类文件生成派生图：`build/framework/nodes.jsonl` + `edges.jsonl` |

派生文件可随时重跑重建；**权威只在 `volumes/` 与 `knowledge_points/`**。

## 状态字段的含义（不许含糊）

- `verified` / `verified_content`：这一册的目录**对着 2024 版新教材 PDF 逐页核过**，页码可用。
- `content_draft`：该节已有知识点，但**该册版次未核**（旧版电子课本），知识点只能算草稿。
- `verified_skeleton`：册次已核（目录可信），但该节还没有知识点。
- `stub_edition`：**目录来自旧版电子课本**，章名与节名大体沿用，但 2024 新教材可能有增删或顺序调整，未核对前不得当作定稿。
- `ai_draft`（节点/边）：内容由规则或模型生成，未经人核对。

章节号（第 10–26 章）沿用北京版六册连续编号，**不另造一套编号**——孩子在书上看到什么号，这里就是什么号。

## 怎么核对一册（约 10 分钟）

1. 打开该册 PDF，翻到目录页（一般第 5–9 页）。
2. 对照 `volumes/<id>.json`：章名、节号、节名、起始页码是否一致。
3. 不一致就改 JSON 里的值，并把 `edition.verified` 改 `true`、`edition.note` 写上"对 XX 版 PDF 第 N 页核对，日期"。
4. 重跑 `python tools/framework_gen.py`，看 `build/framework/report.txt` 的计数是否仍与目录一致。
