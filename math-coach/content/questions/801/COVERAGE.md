## 知识点清单（按节）

### 12.1 三角形（6 个知识点 / 84 题）
- 三角形的定义：不在同一直线上的三条线段首尾顺次相接组成的图形
- 三角形的记法：用符号“△”表示，△ABC读作三角形ABC
- 三角形的元素：三个顶点A、B、C，三条边AB、BC、CA，三个内角∠A、∠B、∠C
- 三角形的稳定性：三边确定后，三角形的形状和大小固定不变
- 稳定性的应用：新首钢大桥的斜拉索与主梁构成许多三角形
- 易错：三点共线或三条线段不首尾顺次相接，都不能构成三角形

### 12.2 三角形的性质（10 个知识点 / 95 题）
- 三角形三边关系定理：任意两边之和大于第三边
- 三边关系推论：任意两边之差小于第三边
- 第三边取值范围：已知两边a、b，则|a-b|<第三边<a+b
- 等腰三角形名称：相等的两边叫腰，另一边叫底边，两腰夹角叫顶角，腰与底边夹角叫底角
- 三角形按边分类：不等边三角形与等腰三角形，等边三角形是特殊的等腰三角形
- 易错：等腰三角形需分类讨论已知边为腰还是底，并用三边关系检验能否组成
- 三角形内角和定理：三角形三个内角的和等于180°
- 内角和定理的证明：过顶点作平行线，把三个内角移到一起拼成平角（辅助线）
- 三角形外角：内角的邻补角；外角等于与它不相邻的两个内角的和
- 三角形按角分类：锐角、直角、钝角三角形，内角中最多有一个直角或钝角

### 12.3 三角形中的主要线段（8 个知识点 / 86 题）
- 中线：连接三角形一个顶点和它对边中点的线段
- 重心：三角形的三条中线交于一点，这个点叫作三角形的重心
- 角平分线：角的平分线与对边相交，顶点与交点之间的线段
- 高：顶点向对边所在直线引垂线，顶点与垂足之间的线段
- 三条高的位置：锐角三角形交于形内，直角三角形交于直角顶点，钝角三角形交于形外
- 易错：钝角三角形有两条高落在边外，垂足在边的延长线上，作图需延长对边
- 中线分面积：三角形的中线把三角形分成面积相等的两个三角形
- 易错：三角形的角平分线、中线、高都是线段，不是射线或直线

### 12.4 全等三角形（7 个知识点 / 84 题）
- 全等形：能够完全重合的两个图形叫作全等形
- 全等三角形：能够完全重合的两个三角形，用“≌”表示，读作“全等于”
- 对应元素：互相重合的顶点、边、角分别是对应顶点、对应边、对应角
- 全等三角形性质：对应边相等，对应角相等
- 全等的记法：按对应顶点顺序书写，如△ABC≌△MPN
- 平移、翻折、旋转前后的两个三角形全等
- 找对应元素：先按全等式中字母位置对应，公共边、公共角、对顶角常是对应元素

### 12.5 全等三角形的判定（10 个知识点 / 88 题）
- ASA：两角及其夹边分别相等的两个三角形全等
- SAS：两边及其夹角分别相等的两个三角形全等
- SSS：三边分别相等的两个三角形全等
- AAS：两角分别相等且其中一组等角的对边相等的两个三角形全等
- 全等证明的格式：在△ABC和△DEF中列出条件，结论后注明判定依据
- 易错：SSA即两边及其中一边的对角分别相等，不能判定两个三角形全等
- 隐含条件：公共边、公共角、对顶角相等可直接用于判定
- 辅助线：连接对角线（如连接AC）可构造出全等三角形
- 补条件题：给出部分相等条件，需选择能成立的判定方法
- 全等的用途：证线段相等、角相等，通常先证全等再得对应元素相等

### 12.6 等腰三角形（10 个知识点 / 102 题）
- 等腰三角形性质定理1：等边对等角，两个底角相等
- 等边对等角的证明：作顶角平分线，用SAS证两个三角形全等
- 等腰三角形性质定理2：三线合一，底边上的高、中线与顶角平分线重合
- 三线合一的应用：取底边中点连接顶点，即得顶角平分线，可用直尺作图
- 等腰三角形是轴对称图形，顶角平分线所在直线是它的对称轴
- 等边三角形性质：各角都相等，都等于60°
- 等腰三角形判定定理：等角对等边
- 等边三角形判定：三个角都相等，或有一个角是60°的等腰三角形
- 易错：已知一边求另外两边，需按该边为腰或为底分类并检验三边关系
- 易错：已知一个角求另外两角，需讨论该角是顶角还是底角

### 12.7 直角三角形（8 个知识点 / 85 题）
- 直角三角形记作Rt△ABC，直角所对的边叫斜边，另两边叫直角边
- 直角三角形性质定理：直角三角形的两个锐角互余
- 直角三角形判定：有两个角互余的三角形是直角三角形
- HL：斜边和一条直角边分别相等的两个直角三角形全等
- 易错：HL只适用于直角三角形，条件是斜边与一条直角边
- 直角三角形全等也能用SAS、ASA、AAS、SSS判定
- 易错：SSA不是全等判定，只有“直角、斜边、一直角边”才是HL
- 两条边上的高相等的三角形是等腰三角形

### 12.8 尺规作图（10 个知识点 / 88 题）
- 尺规作图：只用无刻度直尺和圆规作图，直尺不能度量长度
- 基本操作：过两点作直线（射线、线段）、延长线段、以已知点为圆心定长为半径作弧
- 作一条线段等于已知线段：在射线上以端点为圆心截取
- 作一个角等于已知角，依据是SSS全等
- 作角的平分线：以两边上等距点为圆心，半径需大于½DE，两弧才相交
- 角平分线性质：角平分线上的点到角两边的距离相等
- 角平分线判定：角的内部到角两边距离相等的点在角的平分线上
- 线段垂直平分线：垂直于线段且过中点的直线，线上点到两端距离相等
- 线段垂直平分线判定：到线段两端距离相等的点在垂直平分线上，据此作中垂线
- 作三角形：已知三边、两边及夹角、两角及夹边、一直角边与斜边都能作出

### 12.9 逆命题、逆定理（6 个知识点 / 85 题）
- 命题的结构：可写成“如果……那么……”的形式，分条件和结论两部分
- 互逆命题：第一个命题的条件是第二个的结论，结论是第二个的条件
- 原命题与逆命题：把条件和结论交换位置，就得到原命题的逆命题
- 易错：真命题的逆命题不一定是真命题，必须重新判断真假
- 定理：能作为推理依据的真命题
- 互逆定理：一个定理的逆命题也是定理，如“等边对等角”与“等角对等边”

### 12.10 轴对称和轴对称图形（8 个知识点 / 95 题）
- 轴对称图形：沿一条直线翻折后两部分能完全重合的图形，这条直线叫对称轴
- 对称轴是直线，不是线段，画图时应画成直线
- 成轴对称：两个图形沿直线翻折后重合，互相重合的点叫对应点
- 轴对称的性质：成轴对称的两个图形中，对应点的连线被对称轴垂直平分
- 画对称图形：作各关键点关于直线l的对称点，再顺次连接
- 用轴对称转化：点B关于l的对称点C，连AC交l于D，则AD+DB=AC，可求最短路径
- 常见轴对称图形：线段、角、等腰三角形、等边三角形、长方形、圆
- 一个轴对称图形可以有多条对称轴，如等边三角形有3条

### 12.11 勾股定理（9 个知识点 / 86 题）
- 勾股定理：直角三角形两直角边的平方和等于斜边的平方，即a²+b²=c²
- 勾、股、弦：较短的直角边叫勾，较长的直角边叫股，斜边叫弦，勾三股四弦五
- 易错：勾股定理只在直角三角形中成立，c必须是斜边
- 面积法证明：四个全等直角三角形拼成大正方形，(a+b)²=4×½ab+c²，化简得a²+b²=c²
- 已知两边求第三边：斜边c=√(a²+b²)，直角边a=√(c²-b²)，直角边b=√(c²-a²)
- 求等边三角形的高和面积：作高得到直角三角形，再用勾股定理计算
- 在数轴上作出√2、√3、√5等线段：用等距的直角三角形依次构造
- 实际应用：梯子滑落、大树折断、池中芦苇等，先建模为直角三角形再用勾股定理
- 数学文化：赵爽弦图、《周髀算经》中商高“勾广三，股修四，径隅五”的割补证明

### 12.12 勾股定理的逆定理（7 个知识点 / 82 题）
- 勾股定理的逆定理：若三角形三边满足a²+b²=c²，则这个三角形是直角三角形
- 逆定理的证明：构造一个直角边为a、b的直角三角形，用SSS证两三角形全等
- 判定步骤：先确定最长边，再算两条较短边的平方和与最长边平方比较
- 勾股数：3、4、5；5、12、13；8、15、17以及它们的正整数倍
- 易错：最长边不一定是字母c，须先比较三边大小，再算平方和
- 网格或四边形中判断直角：用逆定理证直角三角形，再求面积
- 勾股定理与它的逆定理互为逆定理，可用来互推直角与平方关系
